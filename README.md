## 背诵规则

| 优先级 | 含义 | 复习方式 |
| --- | --- | --- |
| S | 真题考过 2 次以上 | 回忆，目标保留率 0.95 |
| A | 真题考过 1 次 | 回忆，目标保留率 0.92 |
| B | 未考过 | 回忆要点，目标保留率 0.88 |
| C | 未考过且难度高 | 不进入复习循环，考前集中浏览 |

每日新卡量按距考试天数自动推算，也可在首页随时手动调整。

## 使用方法

1. 打开网址，点「开始学习」
2. 看词条名先自己回想
3. 想默写就在输入框里写出释义，点「**对照答案**」（或按回车）—— 会显示标准释义、记忆重合度参考值和你的作答；不想默写就直接点卡片看答案
4. 按实际感觉点「重来 / 困难 / 一般 / 简单」（键盘 `1`–`4`，空格翻面）
5. 程序会自动安排下次复习时间

界面支持 **白天 / 黑夜 / 跟随系统** 三种外观，在「设置 → 外观」里切换，选择会被记住。

学习进度保存在**你自己浏览器的本地存储**中，不会上传到任何服务器。
换设备时用「设置 → 导出备份 / 导入备份」迁移。

## 专题练习

首页底部有三项，按需使用：

| 入口 | 用途 |
| --- | --- |
| **C 级速览** | 63 条冷门词条，考前集中浏览，不计入复习计划 |
| **辨析题** | 41 道历年辨析题。有参考答案的直接看答案，只有题面的给出答题骨架（定性 → 三点论述 → 举例 → 收束）。练过的可以打勾 |
| **真题整题模拟** | 21 组「真题里连着问的概念」，按组出题。考场上名词解释是一题问 2–3 个概念，这个模式练的就是一次调动多个概念 |

统计页还有一块 **易错卡**，把忘过 2 次以上的词条单独列出来，方便集中攻克。

进度只保存在本机浏览器里，超过 7 天没备份时首页会提醒导出。

## 本地运行

```bash
cd 本目录
python -m http.server 8000
```

然后访问 <http://localhost:8000>

> 不要直接双击 `index.html` —— `file://` 协议下浏览器会禁用本地存储，进度无法保存。
